# Nova Client

Fabric client for Minecraft 1.21.4. Needs Fabric Loader + Fabric API.

## Controls
- Right Shift: open GUI
- GUI: left click = toggle module, right click = show settings,
  middle click = set keybind (then press a key; Backspace clears)
- Defaults: R Sprint, B Fullbright, G Flight

## Config
Saved automatically to .minecraft/config/nova.json
(modules on/off, keybinds, every setting)
